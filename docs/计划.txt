## 二、60 天常见电路学习路线（每日一个）

按照「基础→模拟→电源→数字→接口→综合」的顺序递进，前一天的知识是后一天的基础，不要跳学。

### 第一阶段：基础元件与测试电路（第 1-7 天）

打牢无源器件和半导体器件的应用直觉，这是所有电路的基石。

1. 电阻分压与限流电路
2. RC 充放电与延时电路
3. RL 串联与续流电路
4. 二极管半波 / 全波 / 桥式整流
5. 三极管（BJT）共射开关电路
6. 三极管（BJT）共射放大电路
7. NMOS/PMOS 管开关电路

### 第二阶段：运算放大器经典电路（第 8-21 天）

硬件设计中运放用得最多，必须做到「看到电路就知道功能，说出功能就能画出电路」。
8. 反相比例运算放大器
9. 同相比例运算放大器
10. 电压跟随器（缓冲器）
11. 差分运算放大器
12. 加法 / 减法运算电路
13. 积分运算电路
14. 微分运算电路
15. 电压比较器（开环）
16. 滞回比较器（施密特触发器）
17. 精密全波整流电路
18. 一阶有源低通滤波器
19. 一阶有源高通滤波器
20. 文氏桥正弦波振荡电路
21. 三角波 / 方波发生器

### 第三阶段：电源管理电路（第 22-31 天）

电源是硬件产品的心脏，也是最容易出问题的部分，必须重点掌握。
22. 固定三端线性稳压（7805/7812）
23. 可调线性稳压（LM317）
24. LDO 低压差稳压器电路
25. Buck DC-DC 降压电路
26. Boost DC-DC 升压电路
27. Buck-Boost 升降压电路
28. 锂电池充电管理（TP4056）
29. 过压 / 过流 / 反接保护电路
30. 电源缓启动电路
31. 电源滤波与去耦电容设计

### 第四阶段：数字与接口电路（第 32-45 天）

嵌入式开发最常用的外围电路，工作中天天会碰到。
32. 555 定时器多谐振荡
33. 555 单稳态触发器
34. 按键消抖电路（硬件 + 软件思路）
35. 光电耦合器隔离电路
36. 继电器驱动电路
37. MOS 管大功率驱动电路
38. RS232 电平转换（MAX232）
39. RS485 总线接口电路
40. I2C 总线接口与上拉设计
41. SPI 总线接口电路
42. USB 5V 供电与保护电路
43. 74HC595 串转并扩展电路
44. 74HC138 译码器电路
45. 电平转换电路（3.3V↔5V）

### 第五阶段：传感器与信号调理（第 46-55 天）

模拟信号采集是硬件设计的核心能力，直接决定产品精度。
46. NTC 热敏电阻温度检测
47. 分压式电压采样电路
48. 采样电阻电流检测电路
49. 霍尔传感器检测电路
50. 光电二极管 / 三极管检测电路
51. 仪表放大器（INA 系列）电路
52. 电桥信号放大电路
53. 程控增益放大器电路
54. 二阶巴特沃斯滤波器
55. 4-20mA 电流环发送 / 接收

### 第六阶段：综合应用与保护（第 56-60 天）

结合实际产品场景，整合前面学到的知识。
56. 声光报警驱动电路
57. 电机正反转驱动电路（H 桥）
58. ESD / 浪涌防护电路设计
59. 看门狗与复位电路
60. 典型单片机最小系统电路
