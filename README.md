# 每日一电路 · 硬件设计学习笔记

> 每天学一个常见硬件电路，从原理、元件、选型到 PCB 设计，系统提升硬件设计能力。

## 📖 项目简介

这是一个硬件电路自学笔记项目，按照 **60 天学习路线** 每天深入解析一个常见电路，涵盖基础元件、运算放大器、电源管理、数字接口、传感器信号调理等六大阶段。

每个电路都包含：
- 📄 **学习文档**（Word）：原理讲解、元件作用、公式推导、选型参考、芯片型号、术语解释、学习总结
- 🖼️ **原理图**（SVG）：标准拓扑结构图，矢量清晰、可无损缩放

## ✅ 已完成内容

### 电源管理（DC-DC 开关电源）
- [x] **Buck 降压电路** — 开关斩波 + 电感储能，输出电压低于输入
- [x] **Boost 升压电路** — 电感感应升压，输出电压高于输入
- [x] **Buck-Boost 升降压电路** — 标准反极性拓扑，输出可升可降

### 运算放大器经典电路
- [x] **反相比例运算放大器** — Vout = -(Rf/R1)×Vin，反相放大，存在虚地
- [x] **同相比例运算放大器** — Vout = (1+Rf/R1)×Vin，高输入阻抗
- [x] **电压跟随器（缓冲器）** — Vout = Vin，增益为 1，阻抗变换
- [x] **差分运算放大器** — Vout = (Rf/R1)×(V2-V1)，放大差分信号
- [x] **加法 / 减法运算电路** — 多路信号求和、求差，反相加法
- [x] **积分运算电路** — Vout = -(1/RC)∫Vin dt，方波转三角波
- [x] **微分运算电路** — Vout = -RC×dVin/dt，三角波转方波

### 控制算法
- [x] **PID 控制（比例-积分-微分）** — U = Kp·E + Ki·∫E + Kd·dE/dt，自动控制基础

## 🎨 原理图风格规范

- 黑白简约线条，横平竖直、规范工整
- 底部公共地线，电池符号输入
- 运放三角形顶点朝右（− 在上、+ 在下）
- 电阻矩形 + 两端引脚线，关键节点实心圆点
- 元件标注英文在上、中文在下
- 底部附核心公式与图题
