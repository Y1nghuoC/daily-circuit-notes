# 每日一电路 · 硬件设计学习笔记

> 每天学一个常见硬件电路，从原理、元件、选型到PCB设计，系统提升硬件设计能力。

## 📖 项目简介

这是一个硬件电路自学笔记项目，按照 **60天学习路线** 每天深入解析一个常见电路，涵盖基础元件、运算放大器、电源管理、数字接口、传感器信号调理等六大阶段。

每个电路都包含：
- 📄 **学习文档**（Word）：原理讲解、元件作用、公式推导、选型参考、芯片型号、术语解释
- 🖼️ **原理图**（SVG）：标准拓扑结构图，矢量清晰

## 📝 每日学习流程

| 环节 | 时长 | 内容 |
|------|------|------|
| 原理学习 | 10 min | 搞懂功能、元件作用、核心公式 |
| 仿真验证 | 15 min | LTspice搭电路，观察波形变化 |
| 工程思考 | 10 min | 器件选型、PCB布线、可靠性 |
| 总结归档 | 10 min | 写学习文档、记录踩坑点 |
